How to interpret the results

Counterexample found

A concrete model makes the property false while every retained axiom is satisfied. Its valuation is independently replayed before being returned.

Holds within bounds

The checker exhausted the selected scope or bounded search without finding a counterexample. This is finite evidence, not an unbounded proof.

Incomplete or inconsistent

A limit leaves the question open. If the axioms have no model in the selected scope, no property is reported as proved.

Truth values, downloads, and privacy

t means true, b means broken, and f means false. Axioms are satisfied by either t or b. A counterexample makes a property f.

Save a counterexample’s Markdown theory and JSON valuation together. Replay them with python -m muql replay theory.md countermodel.json.

Your theory and results stay on your device. Custom theories are saved as a draft in this browser when local storage is available. Each visit starts at First steps; restore your draft in Custom experiment below the results. Browsing the curated examples leaves your saved draft intact. The Python runtime loads when you first use the checker; MiniSat loads an additional package if selected. The standard online build fetches these from jsDelivr; a self-contained build can serve them with the page. There is no account or analytics. Closing the page stops computation.
