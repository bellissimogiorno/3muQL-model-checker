# Release notes

## Current release

3μQL Explorer includes a Python CLI, a local browser server, a GitHub Pages
application, executable protocol theories and a self-contained theory reader.
Backward and forward rule labels use `?` and `!`, including `BrReady!!`.

The main guides place the GitHub Pages explorer link at the top so readers can
open the implementation directly. This package was vibe-coded following prompts
by Murdoch J. Gabbay.

The complete source, four release distributions, current validation records and
reproducible build tools are supplied. See [validation](docs/validation.md) for
executed checks and [GitHub setup](docs/github.md) for publishing.
